how-many-tabs-do-you-have-open is a tiny Node 22 program that writes one
honest tab count — digits only, nothing else — to `/output/entry.txt`:

> 137

The count is **137**. Most people guess a field of ten to forty tabs, so
137 surprises; it is odd and specific, not a round 100 or 150, so it reads
as a number someone actually counted rather than one picked to shock; and
it is a count a real tab hoarder can genuinely have open right now —
several windows of research, docs, half-read articles and "I'll get back
to this" tabs accumulated over weeks. Three digits, one number, no words.

## Run it

```sh
node main.ts
```

This writes the entry text to `/output/entry.txt` (UTF-8). It uses the
Node standard library alone: no install step, no dependencies, no network.
Two runs write byte-identical output.
